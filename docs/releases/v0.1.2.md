## NX Node v0.1.2

> **Update the panel to v0.1.2 first**, then update each node from the
> panel's Nodes page. A node on v0.1.1 keeps working with the new panel; it
> lacks DTLS for OpenConnect and the WARP+ licence key below.

- **OpenConnect DTLS connects again** (#1). Since a library update every
  AnyConnect DTLS handshake was refused, so clients stayed on the slower TLS
  channel. DTLS sessions now resume, a client that leaves without saying so is
  noticed after 30 seconds, an idle one is dropped after 70, and a failed DTLS
  handshake is logged as a warning naming the user.
- **WARP+ licence key.** A WARP outbound can carry a WARP+ key, which is put on
  the node's own WARP device without registering a new one. A refused key (past
  its device limit, or mistyped) is logged with Cloudflare's reason and the
  node stays on free WARP. A WARP outbound that names an existing profile by id
  and token now enrols; before, it never did.
- **Nothing in a config can start a program.** OpenConnect's wrapper paths,
  Tor's executable path, extra arguments and transport plugins, and
  Tailscale's SSH server make the node refuse the configuration, naming the
  option, however the key is spelled. Panel v0.1.2 leaves them out of what it
  sends, so update the panel first.
- **Tor and log files stay in the node's cache.** A Tor outbound's data
  directory and a log file named in the core settings are kept under the
  node's `cache/` directory instead of the path as typed.
- An outbound check now has its full time on the node before the panel gives
  up, so a server that never answers reads *timed out*.
- Updated dependencies; built with Go 1.27.4, which fixes a security issue in
  its HTTP library.
