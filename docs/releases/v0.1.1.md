## NX Node v0.1.1

> **Update the panel to v0.1.1 first**, then update each node from the
> panel's Nodes page. A node on v0.1.0 keeps working with the new panel; it
> only lacks the fixes and certificate features below.

- **OpenConnect clients stay connected** (#1). The OpenConnect server sent each
  packet's header and payload as two TLS records, so OpenConnect and every
  other client built on libopenconnect logged "Unexpected packet length",
  sent BYE and dropped the session right after connecting. Each packet now
  goes out in one record, as ocserv and Cisco ASA send it. DTLS still does not
  connect: clients carry the traffic over the TLS channel instead.
- **tls-alpn-01 on the ingress.** A node's ingress inbound now answers the
  tls-alpn-01 challenge on the port it holds, so the node issues and renews a
  certificate over tls-alpn-01 while the inbound and everything behind it keep
  serving. Before, the challenge failed while the inbound held the port.
- **Four more dns-01 providers**: ArvanCloud, Selectel, Tencent Cloud (DNSPod)
  and Huawei Cloud, with the same credentials as on the panel.
- Fixes a crash in the tls-alpn-01 path.
- Hysteria2's gecko obfuscation, which panel v0.1.1 offers, runs on this node
  and on v0.1.0 alike. Keep its packet sizes at 1452 or less (the panel
  enforces it): a larger piece does not get through.
- The Docker image takes its `libcronet.so` (naive outbound) from the version
  the node is built against, verified, instead of the newest cronet release.
- Updated dependencies; built with Go 1.27.3.
